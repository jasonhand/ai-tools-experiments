Tara Schofield returns for a deeper dive into advanced Claude Code techniques, demonstrating sophisticated workflows for content creation at Datadog. She showcases slash commands for reusable instructions, strategic model selection (Opus for big-picture analysis, Sonnet for execution), and XML annotation techniques for clearer instructions. A key highlight is her use of subagents for unbiased quality validation - separate agents that evaluate work with fresh context and no knowledge of the creation process. The episode covers context management strategies to avoid 'context poisoning,' integration between Cursor's Quick Chat and Claude Code, and auto-accept mode for bulk file generation. Tara demonstrates how Claude can even help write and iterate on its own slash commands and subagent configurations, creating a self-improving workflow system.
